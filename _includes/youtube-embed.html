{% comment %} Click-to-load YouTube facade. Shows a thumbnail + play button; the actual (privacy-friendly, nocookie) iframe is injected only when the visitor clicks — keeps the page light and loads zero YouTube tracking until play. Handler lives in _layouts/default.html. Usage: {% include youtube-embed.html id="VIDEO_ID" title="Title" %} Playlist: pass params="playlist=ID2,ID3" (ad-hoc) or params="list=PLxxxx" (saved). {% endcomment %}
